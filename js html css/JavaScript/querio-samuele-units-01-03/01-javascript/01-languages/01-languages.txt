c: compilato, in quanto il codice viene eseguito nativamente dalla macchina,
Windows e Linux sono scritti in C il che renderebbe impossibile interpretarlo
java: altro, java viene prima compilato in bytecode e poi interpretato dalla macchina virtuale di Java, questo ha lo scopo di avere l'efficenza del compilato senza dover creare un esecutibile diverso per ogni piattaforma
javascript: interpretato in quanto deve essere eseguibile tramite diversi browser
python: interpreatato per semplicità ed immediatezza di esecuzione
php: interpretato per semplicità e rapidita nelle modifiche
